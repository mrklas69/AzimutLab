### Nález 1 — Sez. 119 reportovalo BUG (0,058 byla chybná rotace)
Diagnostika začala výpisem confusion matice + soft metrikou na sémantických skupinách. Hned vyplavalo,
že per-odstín mIoU NENÍ 0,058, ale **0,256 (Bedřichovka) / 0,354 (Blatná)**. Příčina: `temp/eval_real.py`
`__main__` posílal `rot_sign=1.0` (default argv), zatímco `main()` měl default `−1.0` a závěr Sez. 119 +
vizuální overlay používaly `−1`. Ověřeno oboustranně: vynucený `rot_sign=+1` → přesně **0,058** (rotovaný
overlay), `−1` → 0,256/0,354. Tedy Sez. 119 změřilo a zapsalo číslo z CHYBNÉ rotace, ač text tvrdil, že
`−1` je ověřená správná. Vizuál Y/pred/sken s `−1` potvrzuje georef alignment (tvar, žlutý okraj, les,
vesnice sedí).

### Nález 2 — model reálné mapy ČTE (gap je menší, než tvrdilo Sez. 119)
Soft metrika (sloučení odstínů do rodin open-žlutá / les-zelená / voda / mokřad / skály / zástavba):
**pixel-acc 0,895 (Bedř) / 0,880 (Blatná)** = 88–90 % pixelů správně na úrovni runnability-kategorie.
Vizuál to potvrzuje (pred ≈ Y ≈ sken). Poctivá odpověď auditu A1: doménový gap existuje, ale je
KATEGORICKY malý. Pozn. poctivosti: pixel-acc je nadhodnocená pozadím (~80 % plochy); férové soft číslo =
grouped mIoU **0,466 / 0,411**, popředí open 0,79 / les 0,66.

### Nález 3 — per-odstín gap je METRICKÝ, ne kategorický (confusion matice)
- **401↔403 = hlavní žrout** (Bedř: 401 n=372k, **60 % predikováno jako 403**). Open vs rough-open je
  odstínově fuzzy i pro kartografa → granularita labelu, ne selhání modelu. Žere IoU obou (401 0,32 / 403 0,17).
- **Les naopak dobrý:** recall 406 80 % / 408 81 % / 410 74 %.
- **Vzácné třídy kolabují** na ~0 (402, 308, 501, voda Bedř n=489 — bez supportu).
- **Voda:** Blatná 301 recall 98 %, ale IoU 0,32 = modrá halucinace jinde (false positives, viz Sez. 119 vizuál).
- **Striping** (vertikální pruhy) = doménový artefakt. Striping + modrá halucinace = model-improvement,
  mimo dnešní dohodu STOP na modelech (Sez. 118).
