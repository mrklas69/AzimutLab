## Sezení 8 — Vektorizace vrstevnic na ISOM + DRY paleta + ČSOS KB

Osmé sezení projektu, první toho dne. `%BEGIN` proběhl: git čistý/synchronní.
**Audit cadence: LOC práh %AUDIT:CODE poprvé padl** (585 > 500 na začátku sezení,

**DRY paleta** (foundations před dalším růstem kódu). Sezení se pak ad-hoc rozvětvilo
(ČSOS KB → vektorizace vrstevnic → `.omap`).

### Diskuse / co se dělalo

- **DRY paleta — oponováno směru z TODO.** TODO říkalo „paleta → jediný zdroj
  `isom-issprom.md`". Oponováno: runtime konzument je Python, parsovat Markdown za běhu
  je proti KISS. SSoT patří do kódu (`palette.py`), Markdown (spec §5, KB) na něj odkazuje.
  Uživatel souhlasil. Spec §5 ponechán jako jazykově nezávislá metodika + odkaz.
- **Mapový portál ČSOS → KB (ad-hoc požadavek).** Zdroj reálných OB map (cesta B).
  Licenci uživatel neznal → ověřena přímo ze stránky „O projektu": gate ZAVŘENA dvojitě
  (copyright klubů + jen náhledy 96 dpi s vodoznakem). Verify-against-source dotáhl
  „nevím" na jednoznačné NE.
- **Vektorizace vrstevnic — rozpleteny dvě vrstvy DAGu.** Uživatel narazil na „pixelové
  vrstevnice" + AutoTrace. Oponováno: pro náš generátor je AutoTrace ztrátová oklika —
  vrstevnice už JSOU polylinie z contourpy, jen je rasterizujeme do PNG (proto pixelové
  + PIL bez antialiasingu). Vektorizace rastru patří k reálným skenům (UC4-III/UC3).
  `lasertool` (lokální binárka) zhodnocen: LIDAR point cloud→rastr (Karttapullautin rodina),
  naráží na stejnou vegetace gate (multi-echo mračno). Multi-echo lze koupit → odloženo.
- **`.omap` — neslepě bez verify.** OOM nejdřív „nenalezen" (hledal jsem špatnou cestu),
  pak zjištěno, že 0.9.6 má jen `windows` platform plugin → headless konverze nejde.
  Rozděleny role: já píšu + self-verify (XML/struktura/rozsah), uživatel otevře v OOM.

### Rozhodnutí / nálezy

- **`palette.py` jako SSoT:** `PALETTE` slovník (slug→`Swatch(rgb, meaning)`) + odvozené
  `C_*` konstanty (žádná druhá kopie hodnot). Hex↔RGB byly konzistentní, ale na 2-3 místech
  (kód + spec §5 + §4.2-4.5) → reálné DRY riziko, ne hypotetické.
- **Vektor z přesného zdroje, ne z pixelů:** contourpy dává polylinie přímo → GeoJSON
  s ISOM symbolem 101/102. Georef: real = S-JTSK (EPSG:5514, přes zveřejněný
  `dmr.build_bbox`), noise = lokální metry. CRS member jen pro real (GeoJSON-2008,
  OOM/QGIS ho čtou). 103 Form line generátor nedělá.
- **`.omap` template-based (jako Pic2Omap `db2omap`), ale jiný vstup:** db2omap jde
  z rastru (pixel→coord přes .pgw/cv2), my z přesných polylinií → sdílíme jen FORMÁT,
  ne kód (CLAUDE.md: neduplikovat sourozence). Local CRS, paper-space (1 m→100 µm při
  1:10000, vycentrováno, bez Y-flip — gy roste dolů jako paper y). Symbol id z template.
- **ISOM symboly ověřeny** (O-Map Wiki): 101 Contour / 102 Index contour / 103 Form line.
  Malé uzavřené izolinie (lok. extrémy) → kartograficky bodové symboly 112/113/115/116
  (pozorováno uživatelem v .omap; zapsáno jako odložený bod do TODO).

## Sezení 11 — Přestavba generátoru: řez na vrstevnice + cesty (§4.9)

Jedenácté sezení, čtvrté toho dne. `%BEGIN` proběhl: git čistý/synchronní, audit
cadence čerstvá (CODE+DOCS Sez. 9). Fokus z „Příště" Sez. 10: cesty (§4.9, `[!]`).
Sezení se zlomilo: po volbě metody cest přišel od uživatele požadavek **zahodit
plošné vrstvy a generátor přestavět „znovu a lépe"** (vrstevnice → cesty → …).
**Pozn. k přechodu strojů:** sezení končí přechodem **mrkla → ntbhej**; git je SSoT,
na druhém stroji stačí `%BEGIN` (pull + tento záznam), kód bude synchronní.

### Diskuse / co se dělalo

- **„Cesty ze ZM5" — oponováno dvěma pastmi + křižovatkou.** Uživatel navrhl převzít cesty
  502-507 ze ZM5. Oponováno: (1) **ZM5 je zrušený rastr** (1.7.2023 → ZTM5); vektor komunikací
  je v **ZABAGED Polohopis** (WFS, CC BY 4.0) — z rastru by se cesty musely zase segmentovat
  (ztrátový UC4-III problém). (2) **„Není těžší než contours" neplatí:** vrstevnice počítáme
  z gridu, co držíme (DMR 5G); ZABAGED je nový datový kanál (WFS, parsování, mapování na ISOM,
  rasterizace). (3) **Křižovatka procedurální vs data-driven:** §4.9 je procedurální (UC4-I),
  ZABAGED je UC2→UC4-II a funguje jen pro real terén (noise nemá souřadnice). Nabídnuty 3 cesty
  (A procedurální / B ZABAGED real / C hybrid). **Uživatel zvolil A** — ZABAGED → IDEAS jako
  samostatný enabler.
- **Požadavek „zahodit a přestavět lépe".** Uživatel: zahodit balvany, vegetaci, bažiny
  („divné plusové okraje"), stavět znovu — vrstevnice + cesty. Oponováno proti plošnému mazání
  (GT ztráta) → vyjasněno přes Q1-Q3: **A1 = vizuální věrnost** (vrstvy vypadaly uměle, ne
  problém přístupu), **A2** vrstevnice + body 112/113/115 + vektor/`.omap` zůstávají, **A3**
  cíl sezení = vrstevnice + cesty (→ řez, ne architektonický přepis). Princip přijat: špatně
  vypadající vrstva kazí domain gap feederu → zahodit ji je oprava, ne destrukce.

### Rozhodnutí / nálezy

- **Řez (`generator.py`):** pryč §4.2 vegetace, §4.3 paseky, §4.4 bažiny, §4.11 balvany +
  mrtvá pole, co na nich visela (`slope/eb/gradient`, `_to_pixels`, `box_blur`, `_draw_dotted`)
  + masky `mask_veg/water/rock` + meta `veg_classes`. Import palety zúžen na 3 reálně použité
  barvy (bílá/hnědá/černá). `generate()` se zeštíhlil, moloch zmizel sám (řez, ne přepis — A3).
- **Cesty (§4.9):** `n = 1+round(det*1.6)`, waypointy okraj→okraj (H/V) + kolmý jitter,
  Catmull-Rom. Hlavní plná černá (ISOM **503**, 2 px) / vedlejší čárkovaná (ISOM **505**).
  Nové helpery `_catmull_rom` (reusable — až přijdou rýhy/toky §4.6/4.8, použijí ho) a
  `_draw_dashed` (čárkování po délce oblouku, kreslí mapu i masku). Nový `--det`,
  `mask_paths.png` (multi-class 1/2). Z-order: po vrstevnicích, před body.
- **RNG otázka odpadla:** opatrnost kvůli posunu balvanového streamu byla na stole, ale
  mazáním balvanů zmizel jediný stream k ochraně → cesty losují přímo z `rng`, nejjednodušší.
- **`batch.py`** srovnán na `generate(seed, rug, det, …)` (noise losuje rug+det, real jen det).
- **Spec NEsmazána, označen stav:** §4.9 realizace, §8.1 masky, §4 status box (řez Sez. 11,
  metodika zahozených vrstev zůstává platná pro přestavbu). Spec je dvojí (zadání + prompt) →
  metodika vegetace/bažin je dál platná, jen implementace ji teď nedělá.

### Kód / artefakty
