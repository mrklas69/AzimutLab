### 3. Kód `model/png2point/` (izomorf s png2area)
- **`inject.py`** — `POINT_CLASSES` registr (dataclass: kód/název/radius_mm/sigma/field) + `inject_tile(rgb, seed)`:
  stamp ikonek (plný kruh) na RGB + GT **Gaussian heatmapa** (`_splat` element-wise max, CenterNet
  `draw_umich_gaussian`). Sampler: 204 rozeseté jednotlivé body, 210 jittered POLE teček v elipse (rozestup
  ze spec). PX_PER_MM 7,52 @ 1,33 mpp / 1:10000 + size-jitter ±25 %. Vrací (x uint8, heat[N_POINT,512,512] f32).
  Self-test vizuál (`temp/inject_x.png`, `_overlay.png`) — zarovnání heat↔ikonka sedí.
- **`dataset.py`** — `PointTileDataset`: podklad → (train) D4 + injekce(variabilní seed = nekonečná augmentace) +
  degrade(`generator/degrade.py`, fotometrická → heat zůstává zarovnaná); val/test/overfit deterministická
  injekce (seed=idx). X ImageNet-norm, Y heatmaps. Degradace AŽ po injekci (symboly se degradují jako na skenu).
- **`train.py`** — smp U-Net `classes=N_POINT` + sigmoid; **penalty-reduced focal loss** (CenterNet α2/β4 —
  řeší extrémní peak-vs-pozadí nevyváženost, analog median-freq vah). Metrika = peak NMS (3×3 max-pool) →
  `_peaks_xy` → greedy `_match_counts` v `TOL_PX=3` → **F1 per třída**. BF16, checkpoint best dle val mF1, křivka.

### 4. Overfit gate SELHAL → diagnostika root-cause (`temp/diag_point.py`)
Gate (40 ep, 2 mapy): **mF1 ≈ 0,01** — recall vysoký (0,96), **precision ~0** (model nevyrábí ostré peaky, jen
mírně zvedá heatmapu skoro všude; loss klesá 520→32 ale zůstává vysoká = pozadí se neztlumilo). Diagnostika
(overfit na 1-4 dlaždice + dump heatmapy GT vs pred) odhalila DVA problémy:
- **(a) Úzká sigma 1px peak na full-res 512 NEJDE naučit** — protichůdný gradient (1px nahoru, hned vedle plný
  trest) → model rozmaže globálně. **Fix: sigma 2,5-4 + LR 1e-3** → loss konverguje k ~0,1, pozadí se tlumí
  (mean 0,43→0,03), peaky se ostří.
- **(b) PODKLAD: gen render (sdílený s Png2Area) obsahuje VLASTNÍ bodové symboly** (gen 204/207/208, landmarks)
  identické s injektovanými, ale BEZ GT peaku → **nejednoznačná funkce** („tenhle černý kruh = 204, tamten
  identický = nic"). Důkaz: na ČISTÉM (bílém) podkladu model memorizuje 204 i 210 **perfektně** (loss 0,09,
  204 pred max 0,83, všechny peaky trefené), na gen podkladu selhává **i na 1 dlaždici** (204 pred max 0,29,
  záměna 204↔210, boulders netrefeny). Pipeline tedy funguje — vadí podklad.
