### Diskuse (`%THINK`, zatím bez produkčního kódu)

- **Co je displacement:** objekty blíž než ISOM min. čitelná mezera **0,4 mm ≈ 1,83 px** (`PX_PER_MM ≈ 4,58`)

- **Architektonické tření:** dnes je generování **stream** — `_generate_real_*` stáhne/mapuje/**hned kreslí**.
  Displacement potřebuje vidět všechny vrstvy najednou před renderem → **inverze kontroly** (sběr geometrie
  → resolve → draw). Odhadnut jako největší skrytý náklad, větší než algoritmus.
- **GT konzistence (nejtvrdší požadavek):** posun budovy se musí promítnout do rasteru + `mask_buildings.png`
  + OMAP z jedné posunuté geometrie (jako L1). Námitka „displacement lže o poloze" vyvrácena: **UC5 čte
  MAPU, ne realitu** → posunutá maska je správná GT. Filozoficky shodné s L1 (zvětšená budova taky „lže").
- **Přístupy:** greedy sekvenční / iterativní relaxace (force-based) / displacement field. Pro feeder
  zvažována lehká relaxace s malým N + strop posunu.

### Rozhodnutí / nálezy

- **Hierarchie pevnosti (volba uživatele):** voda + cesty = pevná páteř, budovy ustupují. Kartografický standard.
