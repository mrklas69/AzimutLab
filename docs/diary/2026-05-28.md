## Sezení 29 — Pomocné vrstevnice (form lines, ISOM 103) z DMR

Dvacáté deváté sezení, mrkla. `%BEGIN`: sync 0/0 (HEAD = origin `30fee76`), čistý strom. Audit cadence
nic due (CODE Sez. 27 = 1 sez / LOC pod 500; DOCS Sez. 19 = 9/10; pruning Sez. 17 = 11/12; CALIBRATE 11/15).
Stale „Příště": katalogové vrstvy se drží od Sez. 24, ale ne stale (menu, odškrtává se po jedné). Fokus
z Příště Sez. 28 = skály/balvany — ale uživatel sezení **odbočil** k symbolu ISOM 103.

### Verify-against-source: co je ISOM 103

Uživatel: „zamyslel bych se nad symbolem ISON 103, umíš pro něj získat podklady?" Ověřeno v
`template_classic.omap` (ne z paměti): **103 = Form line** (pomocná/doplňková vrstevnice), NE slope line
(spádovka je 101.1 „Slope line, contour" / 103.1 „Slope line, formline"). Template: dash 2,0 / break 0,2 mm,
hnědá, čárkovaná. Oficiální ISOM popis (z template `<description>`): *„added only where representation would
be incomplete with ordinary contours; **shall not be used as intermediate contours**; only one form line
between neighbouring contours; excessive use must be avoided."*

**Klíčový nález (odpověď na „podklady"):** form line NENÍ datová vrstva ZABAGED — je to **derivace z DMR
výškopisu**, který už čteme pro vrstevnice 101/102. Žádný nový konektor. ALE naivní „vykresli poloviční
vrstevnice" = přesně to, co spec zakazuje (intermediate contours). Skutečná form line = interpretace, kde
je tvar opodstatněný (paralela s reframe projekce/predikce — [[pseudorealistic-phases]]).

### Heuristika (návrh uživatele, A1 + A2)

Diskuse před kódem (mandát uživatele „nechám na tobě"):
- **A2 (mírný svah):** form line jen kde rozestup vrstevnic > `CONST_LIMIT_103`. Realizováno přes **sklon**
  (ekvivalent, KISS): rozestup = `CONTOUR_STEP / sklon` → „rozestup > limit" ⟺ „sklon < `CONTOUR_STEP/limit`".
  `CONST_LIMIT_103` = `FORMLINE_SPACING_LIMIT_M` (40 m).
- **A1 (složitější polynom):** form line nekreslit tam, kde by byla rovnoběžná s vrstevnicemi (zbytečná).
  Formalizováno jako **křivost terénu** = `|Laplacián výšky|` (druhá derivace). Rovnoměrný svah = lineární
  (polynom 1. stupně) → Laplacián ≈ 0 → vynecháno. Kopeček/deprese/sedlo = nenulový → kreslí se.
- **Maska = (sklon < práh) AND (|Laplacián| > práh).** `elev` se 3× vyhladí (3×3 box `_box_smooth`) před
  derivacemi — tlumí mikro-texturu DMR (Laplacián ji jinak zachytí jako falešné form lines všude).

Implementace izomorfní s 101/102: poloviční hladina (`level + 2,5 m`) přes `cont.lines()`, ořez na masku
(`_clip_line_to_mask` = „část pomocné vrstevnice"), filtr min. délky, render dashed hnědě + GT maska + vektor
+ `.omap`. Jen `terrain == "real"` (reálný terénní detail; noise = umělý perlin → form line nemá smysl + drží
proc baseline).

### Kód

- `generator.py`: `ISOM_FORMLINE=103` + `FORMLINE_*` konstanty; `_box_smooth`, `_formline_mask`,
  `_clip_line_to_mask`, `_polyline_len_px`; render blok po hlavní contour smyčce (jen real); `mask_formlines.png`;
  `_build_meta` sekce `formlines` (+ param `n_formlines`); `contours.geojson` přes `contour_features + formline_features`;
  log „pomocné vrstevnice (103)".
- `omap_export.py`: `103` v `USED_CODES`; `write_omap` param `formline_features` (emit jako 101/102 line_object);
  `n_formlines` v návratu.
- `_write_contours_geojson`: `names[103] = "Form line"`.

### Ladění prahů — verify, ne poslepu

První prahy (`curv_min 0,0015`, 1× smooth, min 1,1 mm) → **1466 form lines** na NL 6×4 km (= 6× víc než
240 vrstevnic). Overlay (maska zviditelněná ×255) ukázal **plošný šum** rozesetý po celé mapě — ISOM
„excessive use". Probe `temp/probe_formline.py` (citlivost passes × curv × spacing + distribuce délek):
- curv 0,008 + 3× smooth + min 1,1 mm → 70 (mezikrok).
- **curv 0,004 + min 3 mm → 108** — uživatel chtěl HUSTŠÍ (nižší curv = víc tvarů), ALE bez „fousků"
  (delší min. délka odřízne krátké úseky; medián délky 1,7 mm → 3 mm odřízne spodní ~60 %). Obě kritéria splněna.
- Min. délka 3 mm = ~30 m terén = ~2× ISOM minimum (1,1 mm) — legitimní „ne fousek".

Render break zvětšen 0,2 → 0,5 mm: template 0,2 mm = 0,9 px = sub-px, v rastru neviditelný (form line splývá
s 101). `.omap` nese věrný symbol 103 (OOM renderuje 0,2 mm autoritativně) — stejný render-vs-omap princip
jako u cest/železnice (Sez. 28).

### Verify (ve `.venv`)

- proc baseline **65 drží** (form line jen real → noise beze změny; ověřeno přes `--terrain noise` přepínače).
- NL 6×4 km: **108 form lines** vs 240 vrstevnic. Overlay (form line červeně přes rgb) potvrdil: form line
  jen v **plochých zakřivených partiích** (řídké vrstevnice), strmé svahy (husté vrstevnice) je nemají —
  heuristika funguje dle záměru. Vpravo nahoře i souvislé smyčky kolem depresí.
- Uživatel ověřil `temp/formline_NL/map.omap` v OpenOrienteering Mapper („super").

### Kudos / Censure

### Verify-against-source: ZABAGED skály a ISOM 201–214

**Klíčové zjištění:** žádná vrstva nenese atribut typu/velikosti/výšky (jen `jmeno`). → **KISS:

### Iterace rozhodnutí — drift po stěně argumentů

Diskuse před kódem vedla přes **dvě otočky** (oba úkroky uživatel iniciativně):

1. **A1+A2+A3+A4 (uživatel po Q1–Q4):** „pro balvan jiná značka než pro skály; podklady proložit
   zaobleným mnohostěnem (smoothing); průchodné = 202; lokalita Hrubá Skála". A2 byl explicitní
   pokyn dělat Chaikin smoothing obrysů.
2. **Q1–Q3 finalizace:** MVP 204+207+202(smoothed), hybridní 202 (≤500 m²) vs 206 (>500 m²),
   Chaikin 2 iterace.
3. **Otočka 1 (uživatel v průběhu kódování):** „Skalní útvary není třeba nějak zvlášť
   generalizovat, polygony jsou pěkné." Atribut `Shape_Area` z ZABAGED (OBJECTID 36552 →
   5289,33 m²) ukázal, že polygony mají ~120 vrcholů na 32×32 m → plynulý obrys už bez kreslení.
   **→ Chaikin ZAVRŽEN** (zachován RAW, jako voda/budovy; izomorfní s Sez. 27 lekcí
   „generalizuj jen s důkazem"). `_chaikin_smooth` smazán.
4. **Otočka 2 (uživatel po verify):** „Proč jsou některé polygony vyplněné černou a jiné jen
   obrysem?" Otázka odhalila, že hybridní rozhodování postrádá datový podklad — práh 500 m²
   byl můj návrh schválený, ale „proč zrovna tahle skála s plochou X je masivní a ta s X-1
   ne" se nedá ze ZABAGED odpovědět. **→ Hybridní 202/206 ZAVRŽEN, vše → 206 (plná plocha).**
   `ISOM_CLIFF_PASSABLE`, `ROCK_AREA_GIGANTIC_THRESHOLD_M2`, `_draw_cliff_line`,
   `_polygon_area_sjtsk` smazány. 202 odstraněn z `USED_CODES`.

Konečný stav: **3 ZABAGED vrstvy → 3 ISOM symboly, vrstva = jeden symbol** (KISS, izomorfní
s budovy→521 / vedení→510 / železnice→509). Symbolický návrat ke stejnému principu, který se
osvědčil u všech ostatních vrstev.
