## Sezení 125 — A2a Png2Point re-trénink odhalil seed-nestabilitu → vyřešena focal bias initem (medián 0,888) + ChatGPT audity (HAL3000)

Stroj **HAL3000 (mrkla, CUDA+korpus)**. Fokus z Příště 124 (volba „Go!"): dokončit A2a — Png2Point
re-trénink s purpura augmentací + point re-probe. Z rutinního re-tréninku se vyklubal největší nález sezení:
**Png2Point trénink je vážně seed-nestabilní a „0,897" (Sez. 106) byl nereprodukovatelný outlier.**

### Diskuse / průběh

**A2a Png2Point re-trénink (s purpurou) = červená vlajka.** Re-trénink (40 ep, purpura `APPLY_PROB=0,5`
v `dataset.py`) dal **TEST mF1 0,194** (204 F1=0,03 / 210 0,35) vs Sez. 106 **0,897**. Propad o 0,7 na ČISTÉM
test setu (test cesta `augment=False` → purpura se neaplikuje) → není to citlivost na fialovou, je to regrese
kvality modelu. Measure-first místo zápisu „hotovo".

**Dvoukolová diagnostika (sekce C Fable5: nesahat na závěry před diagnózou).**
1. **Kontrolní běh bez purpury** (`--seed` přidán pro reprodukovatelnost): TEST mF1 **0,417** → DVA problémy:
   purpura sráží (0,417→0,194, Δ −0,22) ALE větší regrese je nezávislá (0,897→0,417).
2. **Vyloučení driftu:** `git diff 01e753e HEAD` tréninkové cesty = jen purpura (+5 ř.); data `gen_pointbase`
   z 06-10 (Sez. 106); split z 06-02; degrade ≤06-09. Kód i data SEDÍ se Sez. 106 → jediná volná proměnná =
   `train.py` **nefixuje seed**.
3. **Multi-seed** (po přidání `--seed`): OFF seedy 0/1/2 = **0,151 / 0,247 / 0,318** (medián 0,247, rozptyl 0,167).
   Determinismus běh nerozbil (3 různé výsledky) → nestabilita reálná. seed=2: 204 F1=**0,01** / 210 0,63 = model
   OBĚTUJE řídké 204 dle inicializace. **„0,897" byl šťastný běh přes nestabilní trénink.**

**Páka 0 (metrologie) + 1 (EMA) — volba uživatele „0+1".** EMA implementována (`--ema`, decay 0,998), ale
EMA běh stuck val 0,013. Kontrola podmínky (baseline trajektorie z `paired_off.log`): model se prvních ~15 ep
**vůbec neučí i BEZ EMA** (val 0,01, precision 0,00 / recall 0,99 = „peak všude"), pak skok. **Smoke 6 ep byl
bezcenný** (nic se neučí do ep ~10) → Censure: vinil jsem EMA decay PŘED kontrolou baseline. EMA je slepá
ulička (decay průměruje mrtvou fázi).

**Skutečný kořen: chybějící focal prior bias init.** `build_model` = `smp.Unet` default bias=0 → sigmoid 0,5
všude na startu → model epochy stlačuje plochou heatmapu dolů (mrtvá fáze) → kdy/jestli skok nastane závisí na
seedu = zdroj rozptylu. Fix = bias = −log((1−π)/π), π=0,01 (RetinaNet/CenterNet). **Pivot EMA → bias init**
(volba uživatele „Go, nech to na tobě").

**Stabilizace POTVRZENA.** Smoke (seed 0, 12 ep, bez EMA): loss ep1 541→2,97, val ep1 0,012→0,310,
**TEST mF1 0,151 → 0,730**, mrtvá fáze pryč, obě třídy živé. Multiseed (3 seedy, 40 ep, bias init):
**medián 0,888 / rozptyl 0,019** (0,878/0,897/0,888) vs baseline 0,247 / 0,167 = **+0,64 medián, 8,8× menší
rozptyl**, 204 ~0,92 / 210 ~0,86 stabilně. 0,888 ≈ 0,897 → Sez. 106 nebyl přehnaný, jen nereprodukovatelný.

**Purpura dopad** (paired seed=0, ON vs OFF stejný seed): ON−OFF = **−0,043** = mírně škodí, podružné vůči
nestabilitě. Doměřit na stabilním modelu = Příště.
